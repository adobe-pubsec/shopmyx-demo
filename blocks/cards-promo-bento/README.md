# cards-promo-bento

Custom **cards** block. Purpose: Linked promo tiles in a bento grid; each group of three has one double-width tile (first in odd rows, last in even rows).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card, 2 cells (Image | Destination link). Insert the image in the left cell (a Dynamic Media image is a link to its image URL); put the page it should open as a link in the right cell. The whole image becomes clickable; the link text is not shown and is used as the accessible label only when the image has no alt text.

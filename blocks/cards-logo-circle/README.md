# cards-logo-circle

Custom **cards** block. Purpose: Row of circular linked brand/program logos.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card, 2 cells (Logo image | Destination link). Insert the image in the left cell (a Dynamic Media image is a link to its image URL); put the page it should open as a link in the right cell. The whole image becomes clickable; the link text is not shown and is used as the accessible label only when the image has no alt text.

## Supported variations

No variations.

# cards-icon-feature

Custom **cards** block. Purpose: Centered feature items with a line icon, uppercase title and one or two linked lines.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card, 2 cells (Icon image | Title (heading, linked to the destination) and linked lines). The icon opens the same page as the title link.

## Supported variations

No variations.

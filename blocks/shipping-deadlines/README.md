# shipping-deadlines

Custom **shipping-deadlines** block. Purpose: Holiday shipping deadline panel with CSS calendars.

Model: `standalone`

Single block table. Content: Title row (heading + link); art row (Left image | Right image); deadline rows (Group | Date e.g. Dec 16 | Label, optional); note row (single text cell). Rows are detected by content.

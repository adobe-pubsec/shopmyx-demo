# columns-promo-strip

Custom **columns** block. Purpose: Thin strip of two linked promo images at the top of the homepage.

Model: `standalone`

Single block table. Content: one row per promo, 2 cells (Image | Destination link), same as every linked-image block. The promos are shown side by side in row order.
